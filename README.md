# GlowNest Beauty Suite

Create a modern, professional, fully responsive website for a beauty and wellness salon called “GlowNest Beauty & Wellness”.

The website should have a premium, elegant, feminine design with a clean layout, smooth animations, beautiful typography, and high-quality salon/beauty images.

Pages and Sections:

Home Page

Attractive hero section with a large salon image

Heading: “Feel Beautiful. Feel Confident.”

Short description about GlowNest

“Book an Appointment” CTA button

“Explore Services” button

Featured services section

Special offers section

Customer testimonials

Instagram-style gallery

Footer with contact information and social media links

Services Page
Create service categories:

Hair Styling

Hair Coloring

Facial

Makeup

Manicure & Pedicure

Spa & Massage

Bridal Packages

Each service should show:

Service name

Short description

Duration

Price

“Book Now” button

Appointment Booking
Create a booking form where customers can select:

Name

Phone number

Email

Service

Preferred stylist

Date

Time

Additional message

After submitting, show a professional booking confirmation message.

Our Team
Display salon professionals with:

Profile photo

Name

Position

Specialization

Years of experience

Offers & Packages
Create attractive cards for:

Bridal Package

Hair + Facial Combo

Spa Package

Weekend Special

Include original price, discounted price, and “Book Now” button.

Gallery
Create a responsive image gallery showing:

Salon interior

Hair styling

Makeup

Nail art

Spa

Bridal makeup

Add hover effects and a lightbox when an image is clicked.

Reviews
Display customer reviews with:

Customer name

Profile image

5-star rating

Review text

Contact Page
Include:

Address

Phone

Email

Opening hours

Google Maps section

Contact form

Social media links

Admin Dashboard

Create a simple admin dashboard where the salon owner can:

View appointments

Change appointment status

Add/edit/delete services

Manage prices

Add/edit offers

View customer information

Design Requirements

Modern premium salon aesthetic

Responsive design

Mobile-first layout

Smooth scrolling

Subtle animations

Hover effects

Rounded cards

Clean navigation bar

Sticky “Book Appointment” button on mobile

Accessible color contrast

Professional footer

Technical Requirements

Use React + Vite for the frontend.
Use CSS/Tailwind CSS for styling.
Use reusable React components.
Use React Router for multiple pages.
Use proper form validation.
Use sample data for services, team members, offers, and reviews.
Structure the project cleanly so that a backend/database can be connected later.

Make the website look like a real business website rather than a basic student project.
